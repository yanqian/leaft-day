# 功能路线图

状态：规划完成，18 项均未实现。用户当前仅要求整理；下一步需用户明确开始开发。

## 阶段

1. F001–F004：工具链、可运行骨架、测试素材与本地存储。
2. F005–F012：授权和媒体、稳定回顾、首页/手势、收藏与待删。
3. F013–F015：相似分析、人工比较、集中复核。
4. F016–F018：系统删除、异常核对、真机体验。

## 拆分依据

媒体加载、视频生命周期、系统收藏和实际删除属于不同失败边界；相似分析与人工选择可独立验证；本地待删不能与系统删除合并；删除执行与崩溃后核对分别验收。环境和素材能力先于产品功能。每项实现/测试路径与最多三条具体验收记录在 [feature_list.json](../.agent-harness/feature_list.json)。

依赖是规划元数据，不假设调度器自动强制执行；每项启动前核对依赖已完成。F018 不取代逐项测试。A01–A09 的建议默认值在对应 Feature 实施前检查；用户改变决定时同步原需求与任务，不偷偷扩大范围。
