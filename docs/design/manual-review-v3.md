## 用户反馈与定位

1. 继续回顾/随机时光/去年的今天经常只有一项，无法滑动。代码 ReviewTimeline 按同日且相隔不超过2小时分片段，random 对片段等概率采样，ReviewSession 不跨片段。截图1/1说明至少该次无下一项，不足以判定手势再次失效。lastYearToday已拼接匹配日所有片段，真正只有一张时应明确范围，不能假称同日还有照片。
2. 复核长说明应首次提示、其后按需展开。用户明确残留位置是“App 的待删复核/确认清单还在显示”，不是系统照片图库。DeletionConfirmationView成功后只写resultMessage，仍渲染frozen.targets；这是已确认的界面路径，具体手机系统回执未读取。
3. 浏览底栏仍厚重；portraitToolbar使用190pt大面板与默认regular玻璃。用户希望参考提供的第三张图，并补下一张和重新排日期/数量。

## 批准布局

- 默认所有控件隐藏；轻触显示左上关闭按钮，以及两条分离的轻薄玻璃胶囊。
- 上条：上一张 / 中央两行日期、2/12 / 下一张。关闭退出与上一张明确区分。
- 下条：收藏 / 待删 / 相似 / 撤销。双指缩放保留，等价辅助功能入口不能丢失；视频有独立播放/进度控件，横屏继续适配。
- 媒体丰富背景上的clear玻璃配局部对比衬底与亮色图标；黑边、浅色/杂乱照片和减弱透明度需单独验证。图不是承诺任意背景都长一样，不裁切照片换取玻璃效果。
- 复核用缩略图网格为主；小减号撤回标记，不是立即删原片；收藏/视频标记保留，同组保留对照不能因简化而丢失。
- 删除说明首次提示，后续点击展开。每次删除入口仍有一行影响摘要，系统删除确认保留。图中“可在最近删除中恢复”的正式文案需明确受系统保留期限制，详情保留个人图库范围与恢复边界。
- 成功回执后清除本次匹配待删项并切换结果页；取消/失败保留，未知结果提示核对。仅当剩余数为0显示“待删清单已清空”；若本地保存失败，单独显示系统已删除/记录待核对，不伪报清空。

## 采用的回顾范围

继续回顾可跨片段连续浏览；随机优先连续多张（不足时合理扩大相邻日期范围并显示真实日期范围）；去年的今天严格匹配当天，只有一张显示实际数量，并提供显式“继续看附近日期”。具体批次和范围上限已写入SPEC，不能让三个入口偷偷显示相同无边界图库。
