# v4 — 设置与待删退场

用户先要求设计不修改，再批准 `ui-manual-review-v4-approved.png`：“可以，就按照这个来吧”。

设置采用当前授权照片的有限本地缩略图作为背景，轻微柔化和压暗保证文字可读；没有可用缩略图时显示渐变。权限、数量和有限授权管理保留真实行为，图库说明可展开，完成按钮固定在安全区内。玻璃与浏览/复核共用，减少透明度用不透明回退。

上滑或按钮先耐久保存待删，成功后短暂向上淡出并呈现下一未待删项。过渡期间锁住重复动作；失败不做成功动画。收藏项确认后才执行；照片仍按原比例浏览，视频遵循同样标记流程。

“本轮剩余”指从当前游标向后的会话未待删项，包含当前项；连续接续新批次时数量可增加。待删计数来自真实记录并区别不可访问项。末尾完成为0，不在原照片停留。撤销仍绑定原标记并可返回该项。原片只会在集中复核和系统确认后删除。

此文档与静态稿是设计依据，运行证据另行记录。F018真机/iCloud/大图库验证仍未完成。
