# v8 照片取色与自然渐变

2026-09-30：用户提出背景选择图片本身的颜色，然后自然渐变。本方向替代 v6 晚霞和 v7 固定日光海岸壁纸。此次为设计迭代，未修改 App。

## 视觉与取色规则

- 使用当前照片的 2–3 个主色作为渐变色源；提亮并降低饱和度，避免暗图、强红色照片造成沉重背景。大范围柔和融合，无纹理、无具象风景。
- 玻璃保持透明与细亮边，用深色文字保证浅色背景可读性；危险/成功/待核对仍有独立语义色，不随照片变成不可辨识状态。
- 沉浸浏览保持清晰原片；需要背景的导航与信息页面才展示取色渐变，不把原片模糊成背景。
- 首页从主卡封面取色；相似比较使用当前组的代表照片；待删复核使用首张可用照片。进入确认时冻结本次配色，确认→结果→记录不突兀跳色。
- 删除后只延续提前算出的颜色值，不依赖已删除图片，不为装饰继续缓存已删除原片。退出流程后可丢弃配色。
- 无授权、空库、加载失败或全视频且无可用封面时，使用清淡中性默认渐变。后续视频封面取色能力需要单独确认，不假定现有实现具备。
- 减弱透明度时使用实心高对比卡；减少动态效果时不做颜色运动。未来换图时短暂平滑过渡，并防止旧图异步取色覆盖新图。
